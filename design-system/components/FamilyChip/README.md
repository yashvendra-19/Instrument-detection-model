# FamilyChip

FamilyChip names an instrument family with its colour dot. The seven families come straight from the groups in `classifier.py`.

- Consumer provides: `{instrument}` (mapped with `Taal.familyOf`) or `{family: id}`.
- The colour is a mark, never the only signal: the family name is always printed beside the dot.
- Family ids: western, indian-strings, indian-wind, indian-percussion, electronic, brass, modern-strings. Tokens `fam-*`.
